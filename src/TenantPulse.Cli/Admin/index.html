How it behaves

Intensity multiplies each person's own appetite rather than flattening everyone to the same volume, so quiet people stay quieter than chatty ones. Storyline beats are not scaled — they are scripted to be coherent, and repeating them reads as a stutter.

The two limits are safety ceilings, not targets. Each user is capped at max per user/day minus 2, so raising intensity alone quietly does nothing once that binds, and anything over the hourly ceiling is recorded as Skipped.

Changes apply to the next planned day immediately and are saved beside the journal, so they survive the container being replaced.
